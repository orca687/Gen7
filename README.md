# نرم‌افزار بیوانفورماتیکی Gen7

این نرم‌افزار شامل بخش‌های زیر است:
- تحلیل توالی دی‌ان‌ای
- پایگاه‌های داده و ابزارهای بیوانفورماتیکی
- نمودار منهتن و نمودار کیوکیو
- تعادل هاردی-واینبرگ

### راهنمای دانلود و اجرا:
۱. نسخه آماده اجرا را از ستون سمت راست در بخش **Releases** دانلود کنید.
۲. فایل زیپ را استخراج (Extract) کرده و فایل اجرایی برنامه را باز کنید.
